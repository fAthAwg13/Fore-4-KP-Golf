# Fore(4)KP Golf

Free arcade golf for the **AtGames Legends Pinball 4K**, by **fAthAwg**. It runs natively through General Loader 2.0.

**[Website](https://fathawg13.github.io/Fore-4-KP-Golf/) · [Download the latest release](https://github.com/fAthAwg13/Fore-4-KP-Golf/releases/latest) · [Donate](https://www.paypal.com/qrcodes/p2pqrc/8WFUTNYY9S9BJ)**

- Plunger swing: pull for power, release to hit. The classic 3-tap meter swing is also included.
- 1–4 players with initials entry and saved best rounds.
- Three 9-hole courses: Silverball Pines, Outlane Shores and Mesa Multiball.
- Uses all three screens: the course on the playfield, shot info on the DMD and the scorecard on the backglass.

## Install

1. Download `ForeKPGolf-v1.3f.zip` from [Releases](https://github.com/fAthAwg13/Fore-4-KP-Golf/releases/latest) and unzip it.
2. Copy the `forekp` folder into `/external/` on your USB stick.
3. Launch **Fore(4)KP Golf** from General Loader. On first launch, a setup screen learns your buttons and plunger.

Full controls and settings are in `README.txt` inside the download.

## Bugs

Please [open an issue](https://github.com/fAthAwg13/Fore-4-KP-Golf/issues) and attach `forekp.log` and `forekp-input.log`. Pause › System Info shows which folder they're in.
